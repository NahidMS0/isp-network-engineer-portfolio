# Huawei Switch Monitoring with LibreNMS

Huawei switch monitoring for ISP network operations using LibreNMS.

## Monitoring Features
- Device status and uptime
- CPU and memory utilization
- Interface traffic monitoring
- SFP optical Rx/Tx power (dBm), where supported
- Port status and device health
